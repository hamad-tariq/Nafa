How these figures are calculated

Money market and income fund returns are annualized (MUFAP convention): 10% FYTD means a yearly rate of 10%, not 10% earned since July. Other funds show absolute returns. Compare funds within a category and on the same basis. FY is Pakistan's fiscal year, July to June.

Growth of 100, last move, 1 year, volatility and drawdown use a total-return index rebuilt from each fund's reported FYTD return, so dividend payouts don't look like losses. They cover only the price history collected so far, which varies by fund.

Rank is a fund's position by FYTD return among funds in the same category that quote returns the same way.
